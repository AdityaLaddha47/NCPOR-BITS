# FourCast

A simplified implementation inspired by NVIDIA FourCastNet for Antarctic weather forecasting research.

## Objective

Develop a prototype weather forecasting pipeline for Antarctic stations using ERA5 atmospheric data.

## Target Stations

- Maitri
- Bharati
- Himadri

## Variables

- U10 Wind Speed
- V10 Wind Speed
- 2m Temperature
- Mean Sea Level Pressure

## Planned Workflow

ERA5 Data
→ Preprocessing
→ FourCast Model
→ Forecast Generation
→ Station Extraction
→ Visualization
